# Provenance

This repository is a curated implementation extracted from a private research archive at source
snapshot `b1be900f02a7d9259fff5b3153a2af70b24cdd05`. Its Git history is intentionally independent:
exploratory branches, raw outputs, third-party downloads, and machine-specific execution records
were not imported.

The pretrained runtime is anchored to the immutable Hugging Face revision
`493786fda0855b72f61235068c62cc7b2a11fbec`. The release manifest records source checkpoint
hashes, component tensor hashes, architecture, parameter counts, fitted tensorizer, schema, and
normalization statistics. The repository loader verifies the release file checksums before use.

Compact evaluation summaries in this repository were regenerated against the immutable release.
Historical numbers remain in a separate reference file and are not substituted for fresh output.
